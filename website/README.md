# ai-attestation · Marketing site

Standalone marketing site for **ai-attestation**.

```bash
cd website
npm install
npm run dev
# → http://localhost:3003
```

Optional env:

- `NEXT_PUBLIC_DASHBOARD_URL` — demo dashboard (default `http://127.0.0.1:3002`)
- `NEXT_PUBLIC_GITHUB_URL` — GitHub repo (default `https://github.com/liao-zhizhi/ai-attestation`)
- `NEXT_PUBLIC_PROXY_URL` — proxy URL copied by CTA
